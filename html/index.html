01Mental model: HTML khác Flutter/Compose thế nào

Đọc phần này trước. Phần lớn lỗi HTML của dev mobile đến từ việc coi thẻ HTML như widget: chọn thẻ theo hình dạng thay vì theo ý nghĩa.

Ba lớp: HTML lo ý nghĩa, CSS lo giao diện, JS lo hành vi

Trong Flutter, một widget gộp cả cấu trúc, style và callback. Trên web, HTML chỉ nói đây là cái gì (một nút, một tiêu đề, một danh sách), CSS nói trông thế nào, JS nói làm gì khi tương tác.

Flutter: một widget làm cả ba việc
ElevatedButton(
  style: ElevatedButton.styleFrom(backgroundColor: Colors.deepOrange), // style
  onPressed: save,                                                     // hành vi
  child: const Text('Lưu'),                                            // cấu trúc
)
HTML
<!-- HTML: chỉ nói "đây là một nút" -->
<button type="button" class="btn-primary" id="save">Lưu</button>

<style>
  /* CSS: giao diện, tách riêng, đổi được mà không đụng HTML */
  .btn-primary { background: orangered; color: white; }
</style>

<script>
  // JS: hành vi
  document.getElementById('save').addEventListener('click', save);
</script>

⚠️ Lưu ýĐừng chọn thẻ theo giao diện mặc định. <h3> không có nghĩa là "chữ cỡ vừa", <blockquote> không có nghĩa là "khối thụt lề". Chọn thẻ theo ý nghĩa, rồi chỉnh giao diện bằng CSS.

Block và inline

    
Mỗi thẻ có kiểu hiển thị mặc định. Block (div, p, h1–h6, ul, section…) chiếm hết chiều ngang và tự xuống dòng. Inline (span, a, strong, code, img…) chảy theo dòng chữ.


HTML
<p>Inline nằm <strong>trong dòng</strong> và <a href="#">không xuống hàng</a>.</p>
<div>Block 1: chiếm cả hàng</div>
<div>Block 2: tự xuống dòng</div>

<style>
  /* Muốn Row / Column / Grid thật sự: dùng CSS */
  .toolbar { display: flex; gap: 8px; align-items: center; }  /* ≈ Row */
  .stack   { display: flex; flex-direction: column; gap: 8px; } /* ≈ Column */
  .cards   { display: grid; grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)); gap: 16px; }
</style>

    
📱 Flutter / ComposeBlock giống con của Column với crossAxisAlignment: stretch (full width, không co theo nội dung). Inline giống TextSpan trong RichText / AnnotatedString. Row/Column ↔ display: flex, GridView / LazyVerticalGrid ↔ display: grid.

    
⚠️ Lưu ýwidth, height và margin dọc không có tác dụng với phần tử inline thuần. Đổi sang display: inline-block hoặc block nếu cần.

02Cấu trúc tài liệu

  
Khung bắt buộc của mọi trang. <head> chứa metadata không hiển thị, <body> chứa nội dung.


  

    
Khung tối thiểu


HTML
<!DOCTYPE html>                <!-- bật standards mode, luôn là dòng đầu -->
<html lang="vi">               <!-- ngôn ngữ trang: screen reader phát âm, Google dịch -->
<head>
  <meta charset="utf-8">       <!-- đặt sớm nhất, trong 1024 byte đầu -->
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Cài đặt tài khoản · MyApp</title>
  <meta name="description" content="Quản lý email, mật khẩu và thông báo của tài khoản MyApp.">
  <link rel="stylesheet" href="/css/app.css">
  <script src="/js/app.js" defer></script>
</head>
<body>
  <!-- nội dung hiển thị -->
</body>
</html>

    
📱 Flutter / Compose<head> giống phần cấu hình của MaterialApp (title, locale, theme) cộng metadata trong AndroidManifest.xml / Info.plist. <body> là cây widget hiển thị.

    
⚠️ Lưu ýThiếu meta viewport, mobile sẽ render trang như desktop rộng 980px rồi thu nhỏ. Thiếu <!DOCTYPE html>, trình duyệt vào quirks mode và CSS chạy khác thường.

    
♿ A11yĐừng thêm maximum-scale=1 hay user-scalable=no vào viewport: người dùng không zoom được.

HTML

</p>

HTML
<button type="button" class="open-rename">Đổi tên</button>

<dialog class="modal" id="rename-dialog" aria-labelledby="rename-title">
  <form method="dialog" class="modal-body">
    <h2 id="rename-title">Đổi tên dự án</h2>
    <label for="rename-input">Tên mới</label>
    <input id="rename-input" name="name" required maxlength="60" autofocus>
    <div class="modal-actions">
      <button type="submit" value="cancel" formnovalidate>Hủy</button>
      <button type="submit" value="save">Lưu</button>
    </div>
  </form>
</dialog>

<style>
  .modal { padding: 0; border: 0; border-radius: 12px; max-width: min(440px, 100vw - 32px); }
  .modal-body { padding: 20px; display: grid; gap: 12px; }
  .modal::backdrop { background: rgb(0 0 0 / .5); }
  body:has(dialog[open]) { overflow: hidden; }   /* khóa cuộn trang phía sau */
</style>

<script>
  const dlg = document.getElementById('rename-dialog');
  document.querySelector('.open-rename').addEventListener('click', () => dlg.showModal());
  dlg.addEventListener('click', (e) => { if (e.target === dlg) dlg.close('cancel'); });
  dlg.addEventListener('close', () => {
    if (dlg.returnValue === 'save') rename(dlg.querySelector('input').value);
  });
</script>
