JavaScript & TypeScript cho dev đã quen Dart, Kotlin

Tra cứu nhanh khi code Angular/React hằng ngày. JavaScript ES2023+, TypeScript ở chế độ strict. Mỗi mục đối chiếu với thứ bạn đã biết và chỉ ra chỗ JS/TS khác hoặc dễ gây bug hơn.

Phần A · JavaScript

01Mental model: JS khác Dart/Kotlin thế nào

Đọc mục này trước. Phần lớn bug "khó hiểu" khi chuyển từ Dart/Kotlin sang đều bắt nguồn từ bốn điểm dưới đây.

TypeScript chỉ tồn tại lúc compile

JS là ngôn ngữ dynamic. TypeScript kiểm tra type rồi bị xóa sạch khi build: runtime không biết interface User là gì, không có cast check, không có generic reified.

🎯 Dart / Kotlin tương đương: Dart giữ type lúc runtime (x is List<int> hoạt động), Kotlin xóa generic nhưng class vẫn tồn tại và as có kiểm tra. TS không có gì ở runtime: as chỉ là lời hứa với compiler.

⚠️ Lưu ý: Validate dữ liệu ở "biên" (API, localStorage, URL, form) bằng code thật, ví dụ zod (mục 17). Bên trong app thì tin type.

Một thread, một event loop

Toàn bộ code của bạn chạy trên một thread. Async không làm code chạy song song, nó chỉ cho phép "chờ" mà không chặn. Một vòng lặp nặng sẽ đóng băng UI và mọi callback.

🎯 Dart / Kotlin tương đương: Giống Dart trong một isolate (event loop + microtask). Isolate ≈ Web Worker (memory riêng, giao tiếp qua message). Kotlin coroutines có thể chạy song song thật trên Dispatchers.Default; JS thì không, trừ khi dùng Worker.

Primitive hoặc object; class chỉ là cú pháp bọc prototype

Có 7 kiểu primitive (bất biến, so sánh theo giá trị), còn lại đều là object (so sánh theo reference). class là cú pháp đẹp cho cơ chế prototype: method nằm trên một object chung, và có thể bị sửa lúc runtime.

02Biến & kiểu dữ liệu

const/let, scope, các kiểu primitive, null và undefined, so sánh và truthy/falsy.

const và let

const khóa binding (không gán lại được), không khóa nội dung object. let khi cần gán lại.

🎯 Dart / Kotlin tương đương: const ≈ final (Dart) / val (Kotlin), không phải const của Dart (hằng compile-time). let ≈ var. Muốn bất biến sâu: Object.freeze, readonly, as const (mục 4, 12).

⚠️ Lưu ý: Mặc định dùng const. Không dùng var: function scope và hoisting kiểu cũ gây bug khó thấy.

Block scope, hoisting, TDZ

let/const có block scope. Chúng được "hoist" nhưng không truy cập được trước dòng khai báo (Temporal Dead Zone). Function declaration được hoist toàn bộ.

Kiểu primitive và typeof

Primitive: string, number, bigint, boolean, undefined, null, symbol. Mọi thứ khác (array, function, Date, Map…) là object.

⚠️ Lưu ý: Kiểm tra array bằng Array.isArray, null bằng === null, instance bằng instanceof.

null và undefined

undefined nghĩa là "chưa có / không tồn tại" (biến chưa gán, field không có, hàm không return). null nghĩa là "cố ý để trống".

🎯 Dart / Kotlin tương đương: Dart/Kotlin chỉ có null. Ở TS, field optional name?: string có type string | undefined; JSON từ API thường dùng null. Team nên chọn quy ước rõ.

⚠️ Lưu ý: x == null là ngoại lệ duy nhất được chấp nhận của ==: đúng cho cả null và undefined.

== và ===

== ép kiểu trước khi so sánh với luật rất khó nhớ. Luôn dùng === và !==.

🎯 Dart / Kotlin tương đương: Kotlin == gọi equals(), === so reference. JS === với object luôn là so reference, không có equals để override.

Truthy / falsy

JS cho phép mọi giá trị trong if, &&, ||. Có đúng 8 giá trị falsy, còn lại đều truthy (kể cả [], {}, '0').

🎯 Dart / Kotlin tương đương: Không có khái niệm này: if (list) là lỗi compile. Thói quen if (value) ở JS dễ loại nhầm 0 và ''.

⚠️ Lưu ý: Với số và chuỗi, so sánh tường minh: if (count > 0), if (name !== ''), if (value != null).

Số: NaN, float, BigInt

Chỉ có một kiểu number (IEEE-754 float64). Số nguyên an toàn tới 253−1; lớn hơn dùng bigint.

🎯 Dart / Kotlin tương đương: number ≈ double. Dart a ~/ b và Kotlin Int / Int ↔ Math.trunc(a / b). Kotlin Long ↔ bigint khi vượt 253 (ví dụ ID 64-bit từ backend nên gửi dạng string).

⚠️ Lưu ý: Tiền tệ: lưu theo đơn vị nhỏ nhất (đồng, cent) dạng số nguyên, hoặc dùng thư viện decimal.

03Functions

Function declaration, arrow function, tham số, closure và cơ chế this.

Declaration, arrow, default, rest

Arrow function ngắn gọn và không có this riêng; dùng mặc định cho callback. Function declaration hợp cho hàm top-level được hoist.

🎯 Dart / Kotlin tương đương: Arrow ≈ => của Dart / lambda Kotlin. Rest ...nums ≈ vararg. JS không có overload thật: một hàm, tự kiểm tra tham số (TS có overload signature, mục 11).

⚠️ Lưu ý: JS không kiểm tra số lượng tham số. add() cho NaN chứ không lỗi; TS mới bắt được.

"Named arguments" bằng object destructuring

JS không có named params. Quy ước là truyền một object rồi destructure ngay ở tham số, kèm default.

🎯 Dart / Kotlin tương đương: Dart ({required String name, int age = 18}), Kotlin createUser(name = "An", role = "admin"). Hành vi tương tự, nhưng ở JS đó là một object thật được truyền vào.

Closures & higher-order functions

Function "nhớ" biến của scope nơi nó được tạo. Dùng để giữ state riêng tư, tạo factory, wrapper.

this được gán thế nào

this được quyết định lúc gọi, không phải lúc khai báo: obj.method() → obj; gọi rời f() → undefined (strict mode); new → instance mới; call/apply/bind → gán tay. Arrow function không có this riêng, nó lấy this của scope bao ngoài.

🎯 Dart / Kotlin tương đương: Tear-off obj.method (Dart) và obj::method (Kotlin) luôn gắn với obj. Ở JS, obj.method chỉ lấy ra function trần, mất obj.

⚠️ Lưu ý: Khi truyền method cho setTimeout, addEventListener, thư viện ngoài: bọc arrow () => this.save() hoặc khai báo method dạng arrow field.

04Objects & arrays

Destructuring, spread, optional chaining, array methods, Map/Set, copy và immutability.

Object literal, destructuring, spread/rest

Shorthand { name }, computed key { [key]: v }. Destructuring lấy field ra biến; spread copy nông sang object/array mới.

🎯 Dart / Kotlin tương đương: { ...user, role: 'lead' } ≈ user.copyWith(role: 'lead') / user.copy(role = "lead"), nhưng là shallow copy và JS không kiểm tra tên field (TS thì có). Destructuring ≈ Dart 3 pattern var (:name, :role) = … / Kotlin val (a, b) = pair.

Optional chaining ?. và nullish ??, ??=

?. dừng và trả undefined nếu vế trái là null/undefined. ?? chỉ thay khi null/undefined, khác || thay cả 0, '', false.

Map, Set, WeakMap

Object thường chỉ có key string/symbol. Map nhận key bất kỳ, giữ thứ tự chèn, có size. WeakMap chỉ nhận key object và không giữ object khỏi bị GC (hợp để cache metadata).

🎯 Dart / Kotlin tương đương: Map ≈ Map/LinkedHashMap (Dart), mutableMapOf (Kotlin). Khác biệt: key object so theo reference, không có hashCode/equals để override.

⚠️ Lưu ý: JSON.stringify(new Map(...)) cho "{}". Chuyển trước: Object.fromEntries(map).

Object.keys/values/entries/fromEntries, groupBy

Đi vòng qua entries để map/filter một object. Object.groupBy và Map.groupBy (ES2024) thay cho lodash groupBy.

🎯 Dart / Kotlin tương đương: Kotlin groupBy, mapValues, toMap(); Dart groupBy từ package:collection, map.map((k, v) => MapEntry(k, v * 2)).

Shallow copy, deep copy, immutability

Spread chỉ copy một tầng. structuredClone copy sâu và giữ Date, Map, Set. Object.freeze chặn sửa nhưng cũng chỉ một tầng.

⚠️ Lưu ý: structuredClone không clone function và làm mất prototype của class (instance thành object thường). readonly của TS chỉ kiểm lúc compile, không có tác dụng runtime.

JSON và vòng lặp bổ sung

for...of duyệt giá trị (array, Map, Set, string); for...in duyệt key dạng string của object, tránh dùng với array. JSON.stringify nhận replacer để lọc/đổi giá trị.

05Strings, numbers, dates

Template literal, parse và format số, Intl, và các bẫy của Date.

Template literals & string methods

Dùng backtick cho nội suy và chuỗi nhiều dòng. String bất biến, mọi method trả chuỗi mới.

🎯 Dart / Kotlin tương đương: `${a}` ↔ '$a ${b + c}' (Dart) / "$a ${b + c}" (Kotlin). JS bắt buộc ${} và backtick; nháy đơn/kép không nội suy.

Regex nhanh bổ sung

Regex literal /.../flags. Flag g để lấy tất cả kết quả; named group (?<name>) dễ đọc hơn index.

Parse & format số

Number() chặt (cả chuỗi phải là số), parseInt/parseFloat đọc tới ký tự không hợp lệ. toFixed trả về string. Format hiển thị bằng Intl.NumberFormat.

🎯 Dart / Kotlin tương đương: int.parse/toIntOrNull throw hoặc trả null khi sai; JS trả NaN im lặng. Intl.NumberFormat ≈ NumberFormat của package intl.

⚠️ Lưu ý: Luôn truyền radix: parseInt(s, 10). Kiểm tra kết quả bằng Number.isNaN / Number.isFinite.

Date và các bẫy

Date là một timestamp UTC, mutable, tháng đếm từ 0. Lưu và truyền dưới dạng ISO UTC, chỉ format theo múi giờ khi hiển thị.

🎯 Dart / Kotlin tương đương: Dart DateTime(2026, 1, 15) đếm tháng từ 1 và bất biến; kotlinx-datetime tách Instant/LocalDate. JS gộp hết vào một Date mutable.

⚠️ Lưu ý: Tính toán ngày tháng phức tạp dùng date-fns hoặc dayjs. Temporal API (immutable, có timezone) đang được các trình duyệt triển khai; kiểm tra caniuse trước khi dùng trực tiếp.

08Error handling

try/catch/finally, Error tùy chỉnh, cause, và lỗi trong code async.

try / catch / finally, custom Error, cause

Chỉ có một khối catch; phân loại bằng instanceof. Dùng { cause } để bọc lỗi gốc mà không mất thông tin.

🎯 Dart / Kotlin tương đương: Dart on HttpError catch (e) và nhiều catch của Kotlin ↔ một catch + instanceof. JS có thể throw bất cứ thứ gì (string, số), nên TS coi e là unknown.

⚠️ Lưu ý: Luôn throw Error (hoặc subclass) để có stack trace. Gán this.name trong custom Error để log dễ đọc.

Lỗi trong async code

try/catch chỉ bắt được promise bị reject khi có await. Promise không ai xử lý sinh ra "unhandled rejection".

⚠️ Lưu ý: Bật rule @typescript-eslint/no-floating-promises để bắt lỗi quên await.

09Async & event loop

Phần quan trọng nhất khi chuyển từ Dart/Kotlin: thứ tự chạy, Promise, async/await, hủy tác vụ và bảng đối chiếu.

Event loop: microtask và macrotask

Sau mỗi đoạn code sync, engine chạy hết microtask queue rồi mới tới render và macrotask tiếp theo. Vì vậy Promise.then luôn chạy trước setTimeout(…, 0).

Promise: tạo, then/catch/finally

Promise là kết quả tương lai với 3 trạng thái: pending, fulfilled, rejected. Hàm executor chạy ngay lập tức khi tạo (eager).

async/await: song song và tuần tự

Mỗi await chờ xong mới đi tiếp. Các việc độc lập nên bắt đầu cùng lúc rồi chờ bằng Promise.all.

Lỗi hay gặp: forEach với async

🎯 Dart / Kotlin tương đương: Dart async/await y hệt. Kotlin suspend mặc định tuần tự; song song bằng coroutineScope { async { } }. Khác biệt lớn: Kotlin có structured concurrency (scope hủy thì con bị hủy); JS không có scope, promise "mồ côi" vẫn chạy tiếp.

⚠️ Lưu ý: Quên await không báo lỗi gì: hàm chạy tiếp với một Promise thay vì giá trị. Dùng no-floating-promises và no-misused-promises.

Hủy tác vụ với AbortController

Promise không tự hủy được. Quy ước chung: truyền AbortSignal xuống, hàm nhận signal tự dừng và reject.

🎯 Dart / Kotlin tương đương: Kotlin job.cancel() hủy cả cây coroutine tự động. Dart CancelableOperation hoặc CancelToken (dio). Ở JS phải truyền signal thủ công xuống từng tầng. Trong Angular, RxJS takeUntil/switchMap thường đảm nhận việc hủy.

Generator & for await...of bổ sung

Generator sinh giá trị lười. Async generator là "stream" thuần JS: lặp bằng for await...of.

🎯 Dart / Kotlin tương đương: function* ≈ Dart sync* / Kotlin sequence { yield() }. async function* ≈ Dart async* / Kotlin flow { emit() }. for await ≈ await for / collect.

12Type system nâng cao

Union, narrowing, discriminated union, generics, utility types và các công cụ as const / satisfies.

Union, intersection & type narrowing

TS thu hẹp type trong từng nhánh dựa vào typeof, instanceof, in, so sánh literal, truthiness, hoặc type guard bạn tự viết.

🎯 Dart / Kotlin tương đương: Kotlin smart cast if (x is String) x.length, Dart type promotion. TS mạnh hơn ở chỗ hiểu cả in và so sánh literal. Nhưng type guard tự viết là lời hứa: viết sai thì compiler vẫn tin.

Discriminated union + exhaustive switch

Mỗi nhánh có một field chung (status, kind, type) với giá trị literal khác nhau. Gán vào never ở default để compiler báo lỗi khi thiếu case.

Cùng ý tưởng ở Kotlin và Dart 3

🎯 Dart / Kotlin tương đương: sealed + when/switch pattern. Khác: union TS là object thường (serialize JSON trực tiếp được), không có class, phân biệt bằng giá trị field chứ không bằng is.

Generics, constraints, default type params

🎯 Dart / Kotlin tương đương: T extends X ≈ Dart T extends X / Kotlin T : X. Không có reified: không viết được value instanceof T.

keyof, typeof, indexed access

Mapped types & conditional types (giới thiệu)

Mapped type biến đổi từng key của một type; conditional type chọn type theo điều kiện. Hữu ích cho thư viện và util, ít khi cần trong code màn hình.

as const, satisfies, as, !

satisfies kiểm tra value khớp type nhưng giữ type cụ thể; as ép compiler tin bạn mà không kiểm tra gì. Ưu tiên theo thứ tự: annotation → satisfies → narrowing → as (cuối cùng).

🎯 Dart / Kotlin tương đương: TS ! trông giống Kotlin !! và Dart !, nhưng hai cái kia throw ngay khi null. TS ! bị xóa khi compile, không kiểm tra gì, nên lỗi lộ ra muộn ở chỗ khác. Tương tự, as của Kotlin/Dart có cast check; của TS thì không.

⚠️ Lưu ý: Mỗi as hay ! là một chỗ type system bị tắt. Thay bằng narrowing (if (!el) throw …) hoặc assertion function.

enum và union of string literals

🎯 Dart / Kotlin tương đương: enum của Dart và enum class của Kotlin là class đầy đủ (field, method, values). Ở TS, kết hợp union + object as const cho cùng tác dụng.

⚠️ Lưu ý: enum không chạy được với chế độ chỉ xóa type (Node type stripping, erasableSyntaxOnly). Thêm lý do để ưu tiên union.

14Structural typing

TS so type theo hình dạng, không theo tên. Đây là khác biệt lớn nhất với Dart/Kotlin về hệ type.

Cùng hình dạng là gán được

Hai type khác tên nhưng có cùng field (hoặc nhiều hơn) thì tương thích. Không cần implements.

Excess property check chỉ áp dụng cho object literal truyền trực tiếp, để bắt lỗi gõ sai tên field. Qua biến trung gian thì field thừa được bỏ qua.

🎯 Dart / Kotlin tương đương: Dart và Kotlin là nominal: class A(val x: Int) và class B(val x: Int) là hai type khác nhau. Ở TS, chúng là một.

Branded types: khi cần phân biệt

Để TS phân biệt hai string mang ý nghĩa khác nhau (UserId và PlanId), gắn một "nhãn" chỉ tồn tại trong type.

🎯 Dart / Kotlin tương đương: Kotlin @JvmInline value class UserId(val v: String), Dart 3 extension type UserId(String v). Branded type đạt cùng mục đích mà không tốn gì lúc runtime.

16Bẫy hay gặp (gotchas)

JSON.parse không validate type

Kết quả là any; type bạn gán chỉ là giả định. Date thành string, số có thể là string.

any lan rộng khắp codebase

Một biến any làm mọi thứ suy ra từ nó cũng thành any, lỗi im lặng tới production.

forEach không chờ await

forEach bỏ qua Promise mà callback async trả về.

['1','2','3'].map(parseInt) bổ sung

map truyền (value, index), nên parseInt nhận index làm radix.

Mutate state rồi set lại cùng reference bổ sung

React, Angular OnPush và signals phát hiện thay đổi bằng reference; mutate tại chỗ thì UI không cập nhật.
