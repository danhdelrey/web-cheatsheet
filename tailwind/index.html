01 · Đọc trước

Bắt đầu & cách đọc một class

Tailwind sinh ra các class nhỏ, mỗi class làm một việc (p-4 = padding 1rem). Bạn ghép chúng thẳng trong markup, giống truyền tham số vào widget. v4 cấu hình bằng CSS, không còn tailwind.config.js. Nó chỉ sinh CSS cho class thực sự xuất hiện trong source.

Giải phẫu một class tương tác

Gõ một class bất kỳ để tách nó thành variant (điều kiện), utility (thuộc tính), giá trị, modifier và xem CSS thật mà Tailwind 4.3 sinh ra.

Cài với Vite (React, Vue, Svelte…)

Plugin Vite là cách nhanh nhất. Không cần PostCSS và không cần file config.

npm i tailwindcss @tailwindcss/vite
// vite.config.ts
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  plugins: [react(), tailwindcss()],
});
/* src/index.css — import một dòng là đủ */
@import "tailwindcss";

Cài cho Angular

Angular CLI đời mới có schematic tự cài. Nếu muốn tự làm thì cấu hình qua PostCSS, vì Angular builder đọc .postcssrc.json.

# Cách 1: tự động
ng add tailwindcss

# Cách 2: thủ công
npm i tailwindcss @tailwindcss/postcss postcss
// .postcssrc.json (cạnh angular.json)
{ "plugins": { "@tailwindcss/postcss": {} } }
/* src/styles.css */
@import "tailwindcss";
⚠️ Lưu ý

Trong CSS riêng của component (styleUrl), muốn dùng @apply hay theme() thì thêm @reference "../../styles.css"; ở đầu file. Nếu không, Tailwind không biết theme của bạn. Xem mục 16.

Chỉ class "nhìn thấy được" mới có CSS

Tailwind quét source code tìm chuỗi trông giống class (bỏ qua file trong .gitignore). Vì vậy không được ghép tên class lúc chạy: chuỗi bg-${color}-500 không xuất hiện nguyên vẹn trong code, nên không có CSS nào được sinh cho nó.

// ✅ Map sang chuỗi đầy đủ
const BG = { danger: 'bg-red-500', ok: 'bg-emerald-500', info: 'bg-sky-500' };
const cls = BG[status];

Bảng dữ liệu từng bước bấm Tiếp

Cùng bảng với bản CSS thuần, nhưng dựng bằng class. Mỗi bước: demo chạy thật, HTML với dòng vừa đổi tô xanh, các class được thêm hoặc bỏ, và CSS mà các class mới sinh ra (biên dịch ngay trong trình duyệt).

  1. HTML ngữ nghĩa, chưa có class

    Dùng đủ <caption>, <thead>, <tbody>, <tfoot> và <th scope>. Khác với HTML trần: preflight của Tailwind đã đặt sẵn border-collapse: collapse và xoá padding, nên các ô dính sát nhau. th vẫn đậm và căn giữa theo trình duyệt.

  2. Viền và bề rộng

    w-full cho bảng lấp đầy cha. border border-slate-300 phải gắn lên từng ô, vì viền không kế thừa. Không cần border-collapse: preflight đã bật sẵn.

  3. Padding, cỡ chữ và căn trái

    px-4 py-2.5 trên mỗi ô (16px ngang, 10px dọc). text-left ghi đè kiểu căn giữa mặc định của th. text-sm text-slate-700 đặt ở table để mọi ô kế thừa.

  4. Header nổi bật, chỉ kẻ ngang

    Bỏ border khỏi mọi ô; thay bằng divide-y divide-slate-200 trên tbody: một đường kẻ giữa các hàng mà không phải gắn class cho từng hàng. Header: bg-slate-50 text-xs uppercase tracking-wide text-slate-500 đặt trên thead cho các ô kế thừa.

  5. Hàng xen màu và hover

    even:bg-slate-50 là :nth-child(even), hover:bg-sky-50 là :hover (v4 chỉ áp trên thiết bị có chuột). Gắn lên từng tr trong tbody. Rê chuột vào bảng để thử.

  6. Cột số căn phải và dòng tổng

    text-right tabular-nums cho cột SL và Thành tiền: chữ số cùng bề rộng nên hàng đơn vị thẳng nhau. Ô tiêu đề cột số bỏ text-left: đừng để text-left và text-right cùng nằm trên một ô, bên nào thắng phụ thuộc thứ tự trong file CSS sinh ra. tfoot có border-t-2.

  7. Badge trạng thái

    inline-flex rounded-full px-2 py-0.5 text-xs tạo viên thuốc. ring-1 ring-inset ring-emerald-600/20 vẽ viền mảnh bên trong mà không làm badge to ra; /20 là độ trong 20%.

  8. Khung cuộn và header dính

    Bọc bảng trong div có max-h-60 overflow-auto rounded-xl border, cho bảng min-w-xl (36rem) để hẹp quá thì cuộn ngang. sticky top-0 chuyển từ thead xuống từng th, kèm nền riêng. Viền của ô sticky không đi theo khi cuộn, nên thay border-b bằng shadow-[inset_0_-1px_0_…].

    Kéo góc phải dưới của khung demo để thu hẹp, hoặc cuộn bên trong bảng.

  9. Gom class lặp lên thẻ cha

    px-4 py-2.5 đang lặp ở mọi ô. Biến thể tuỳ ý [&_td]:px-4 sinh ra selector .class td, nên đặt một lần trên table là đủ. Chỉ gom thứ không bị ô nào ghi đè: .x td có specificity cao hơn class trên ô, gom cả text-left lên sẽ đè mất text-right của cột số.

    Trong Angular/React, cách gọn hơn nữa là tách component <app-table> để chỉ viết class một lần.

📱 Flutter

DataTable(headingRowColor:, dataRowColor: WidgetStateProperty…, columns: [DataColumn(numeric: true)]): numeric: true chính là text-right tabular-nums. Compose không có bảng sẵn: LazyColumn + stickyHeader {} + mỗi hàng một Row với Modifier.weight().

Khác biệt dễ bị bỏ qua

  • Nút bấm không còn cursor: pointer mặc định. Thêm cursor-pointer hoặc viết rule button:not(:disabled) { cursor: pointer; } trong @layer base.
  • Placeholder lấy màu chữ hiện tại ở độ đậm 50%, không còn là gray-400.
  • hover: chỉ áp dụng trên thiết bị có chuột. Hiệu ứng "chạm là đổi màu" trên mobile cần active:.
  • space-y-* đổi selector sang :not(:last-child). Layout dùng con inline có thể lệch vài pixel, nên chuyển sang flex flex-col gap-*.
  • Transform giờ là các thuộc tính riêng. transition-transform vẫn chạy, nhưng transition-[transform] tự viết phải đổi thành transition-[translate,scale,rotate].
  • Sass/Less không được hỗ trợ. Bản thân Tailwind đã đóng vai trò preprocessor.
