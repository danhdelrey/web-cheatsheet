Tra cú pháp nhanh khi code hằng ngày. Mặc định viết theo kiểu hiện đại: standalone component, signals, built-in control flow và functional API. Cú pháp cũ vẫn gặp nhiều trong code base được ghi chú kèm cách viết mới.

01

Angular CLI & Naming convention

Các lệnh dùng hằng ngày và quy tắc đặt tên để code base đồng nhất.

Viết tắt: g = generate, c = component, s = service, d = directive, p = pipe.

⚠️ Lưu ý: Khi nâng version, đi từng major một (20 → 21 → 22) và xem hướng dẫn tại angular.dev/update-guide. Commit trước khi chạy ng update để dễ xem diff migration.

Từ v20, style guide và CLI bỏ hậu tố type cho component/directive/service. Nhiều team vẫn giữ kiểu cũ, quan trọng là thống nhất trong project.

Component = class TypeScript + template + style. Standalone là mặc định từ v19, không cần NgModule.

Standalone component

⚠️ Lưu ý: Quên thêm component/pipe/directive vào imports là lỗi phổ biến nhất (vd. NG8001 "is not a known element"). Không cần ghi standalone: true từ v19.

Bootstrap app (main.ts & app.config.ts)

Mọi provider toàn app khai báo trong appConfig, thay cho AppModule.

Binding trong template

Control flow: @if, @switch

Kiểu cũ: *ngIf="user as u; else loading", [ngSwitch] + *ngSwitchCase. Migrate tự động: ng g @angular/core:control-flow.

Control flow: @for, @let

⚠️ Lưu ý: track là bắt buộc. Dùng id ổn định (track item.id); chỉ dùng track $index khi danh sách tĩnh. Track sai làm DOM bị tạo lại toàn bộ, mất focus và trạng thái input.

05

Directives

Directive gắn hành vi vào phần tử có sẵn. Attribute directive đổi giao diện/hành vi; structural directive thêm/bớt phần tử khỏi DOM.

Built-in: NgClass, NgStyle

⚠️ Lưu ý: Docs Angular khuyên dùng [class]/[style] thay cho NgClass/NgStyle. Hai cách có thể dùng chung trên một phần tử.

host thay cho @HostBinding / @HostListener

Host binding gắn property/class/style và host listener nghe event trên chính phần tử mà directive đặt lên. Nhờ vậy logic chỉ viết một lần trong directive và dùng lại cho bất kỳ thẻ HTML nào (<p>, <td>, <li>…).

Mục đíchhost: { } mớiDecorator cũ

Class'[class.open]': 'open()'@HostBinding('class.open')
Style'[style.color]': 'c()'@HostBinding('style.color')
Attribute tĩnhrole: 'button'—
Event'(click)': 'onClick($event)'@HostListener('click', ['$event'])
Event global'(document:keydown.escape)': 'close()'@HostListener('document:keydown.escape')

Attribute directive: highlight

Attribute directive: click-outside

Đóng dropdown/popover khi click ra ngoài. Lắng nghe document:click qua host, không cần tự addEventListener và gỡ listener.

⚠️ Lưu ý: Nút mở dropdown nằm ngoài phần tử, nên click mở cũng có thể bị coi là "click outside". Đặt directive trên wrapper chứa cả nút lẫn menu, hoặc dùng $event.stopPropagation() ở nút mở.

Structural directive tự viết

Dùng TemplateRef (nội dung bên trong) và ViewContainerRef (vị trí chèn) để quyết định có render hay không. Dấu * là cú pháp rút gọn cho <ng-template>.

⚠️ Lưu ý: Mỗi phần tử chỉ có một structural directive (*). Cần kết hợp thì bọc thêm <ng-container>. Với điều kiện/lặp thông thường, ưu tiên @if/@for.

07

Signals

Signal là giá trị reactive: đọc bằng cách gọi count(), Angular tự biết template/computed nào phụ thuộc vào nó để cập nhật đúng chỗ.

signal, computed

⚠️ Lưu ý: Không mutate trực tiếp (this.items().push(x)). Signal so sánh bằng Object.is, cùng reference thì không báo thay đổi. Luôn dùng set/update với object/mảng mới.

effect

Chạy side effect khi signal đổi: ghi localStorage, log, đồng bộ với API ngoài Angular. Phải tạo trong injection context (constructor/field).

⚠️ Lưu ý: Không dùng effect để tính state từ state khác, hãy dùng computed hoặc linkedSignal. Đọc signal mà không muốn track thì bọc trong untracked(() => ...).

linkedSignal

Giống computed nhưng ghi được. Tự reset theo nguồn khi nguồn đổi, giữa các lần đó người dùng vẫn set được.

resource / rxResource stable v22

Signal cho dữ liệu async: tự gọi lại khi params đổi, có sẵn trạng thái loading/error. Gọi HTTP thì xem httpResource ở mục 11.

Khi nào dùng Signal, khi nào dùng Observable

Giá trị dẫn xuất (tổng tiền, filter list)computedCó cache, tự tính lại
Fetch dữ liệu theo tham sốhttpResource / resourceCó loading/error, tự hủy request cũ

Kết quả cuối hiển thị trên templateSignal (toSignal)Hợp với OnPush/zoneless, không cần async pipe

Quy tắc ngắn: state → signal, event/stream → RxJS, nối hai bên bằng toSignal/toObservable (mục 10).

08

Dependency Injection

Angular tạo và cấp instance cho bạn. Bạn khai báo provider ở đâu thì instance sống ở phạm vi đó.

@Injectable, @Service, inject()

Kiểu cũ: constructor(private cart: CartStore) {}. Migrate: ng g @angular/core:inject; chuyển sang @Service: ng g @angular/core:service (v22.1).
⚠️ Lưu ý: inject() chỉ gọi được trong injection context: field initializer, constructor, factory, hoặc trong runInInjectionContext(). Gọi trong ngOnInit hay callback sẽ lỗi NG0203.

09

Change detection

Cơ chế Angular so sánh lại binding và cập nhật DOM. Hai câu hỏi: khi nào CD chạy (zone.js hay zoneless) và component nào được check (Eager hay OnPush).

Eager (Default) và OnPush

Eager (trước v22 tên là Default)OnPush (mặc định từ v22)
Được check khiMỗi lần CD chạy ở bất kỳ đâu trong appChỉ khi: input đổi reference, event trong template/host của nó, signal đọc trong template đổi, async pipe emit, gọi markForCheck()
Mutate objectUI vẫn cập nhậtUI không cập nhật nếu reference giữ nguyên
Hiệu năngKém dần khi app lớnTốt, bỏ qua cả nhánh cây không đổi
Khi nào dùngCode cũ dựa vào mutate, chưa kịp refactorMọi component mới, nhất là khi dùng signals
⚠️ Lưu ý: Khi ng update lên v22, migration tự thêm ChangeDetectionStrategy.Eager vào component cũ chưa khai báo strategy để giữ hành vi. Nên dần chuyển sang OnPush.

markForCheck với OnPush

Khi dữ liệu đến từ subscribe() thủ công (không qua signal/async pipe), component OnPush không biết mà cập nhật.

zone.js và zoneless

zone.js vá mọi API async (setTimeout, Promise, event) để tự chạy CD sau mỗi tác vụ. Zoneless bỏ cơ chế đó: CD chỉ chạy khi Angular được báo rõ ràng.

Ở chế độ zoneless, CD được kích hoạt bởi: signal.set/update được template đọc, event listener trong template/host, async pipe, markForCheck(), ComponentRef.setInput().

⚠️ Lưu ý: Code gán field trong setTimeout/subscribe từng "tự chạy" nhờ zone.js sẽ không cập nhật UI khi zoneless. Chuyển sang signal. Trong test, dùng await fixture.whenStable() thay cho fixture.detectChanges().

Signals ảnh hưởng change detection thế nào

  • Template đọc signal → Angular ghi nhận component đó là "consumer". Khi signal đổi, chỉ component đó được đánh dấu cần check, không phải cả cây.
  • Signal + OnPush + zoneless là tổ hợp hiệu quả nhất: không cần markForCheck, không cần zone.js, không check thừa.
  • computed có cache: template gọi total() nhiều lần cũng chỉ tính một lần cho mỗi thay đổi.
  • Đổi signal trong lúc đang render (vd. trong computed hoặc getter template) gây lỗi NG0600. Đổi state trong event handler, effect, hoặc callback async.
10

Async & RxJS

Đi theo mạch: Promise → Event Loop → async/await → Observable → Operators. Hiểu event loop giúp đoán đúng thứ tự chạy của code async.

1 · Promise

Đại diện cho một giá trị trong tương lai. Chạy ngay khi tạo (eager), không hủy được.

2 · Event Loop

JS chạy một luồng. Sau khi call stack trống, engine chạy toàn bộ microtask (Promise callback, queueMicrotask) trước, rồi mới lấy một macrotask (setTimeout, event, I/O).

zone.js hoạt động bằng cách bọc chính các task này để biết khi nào chạy change detection.

3 · async / await

Cú pháp viết Promise như code tuần tự. await tạm dừng hàm, phần sau chạy như một microtask.

⚠️ Lưu ý: await trong vòng for làm các request chạy nối tiếp. Request độc lập thì gom vào Promise.all.

4 · Observable

Luồng nhiều giá trị theo thời gian. Lazy (chỉ chạy khi subscribe), hủy được (unsubscribe), biến đổi bằng operator.

Deferrable views

@defer tách phần template (cùng component, directive, pipe bên trong) thành chunk riêng và chỉ tải khi trigger xảy ra. Giảm bundle ban đầu mà không cần sửa routing.

Cấu trúc đầy đủ

  • @placeholder (minimum 300ms): placeholder hiện ít nhất 300ms, tránh nháy.
  • @loading (after 100ms; minimum 500ms): chỉ hiện spinner nếu tải lâu hơn 100ms, và khi đã hiện thì giữ ít nhất 500ms.

Triggers

TriggerTải khi
on idleTrình duyệt rảnh (mặc định nếu không ghi trigger)
on viewportPlaceholder (hoặc on viewport(ref)) lọt vào màn hình
on interactionNgười dùng click/keydown vào placeholder hoặc ref
on hoverDi chuột/focus vào placeholder hoặc ref
on immediateNgay sau khi trang render xong
on timer(2s)Sau một khoảng thời gian
when condBiểu thức cond thành true (chỉ một lần)
prefetch on …Tải trước chunk, render khi trigger chính xảy ra

Ví dụ hay dùng

⚠️ Lưu ý khi dùng @defer

  • Component bên trong phải là standalone và không được tham chiếu ở chỗ khác ngoài block (vd. viewChild(SalesChart), dùng ở template ngoài). Nếu có, nó bị tải eager và @defer mất tác dụng.
  • on viewport, on hover, on interaction không có ref thì cần @placeholder có một phần tử gốc.
  • Khi SSR, server chỉ render @placeholder. Dùng hydrate on viewport (incremental hydration) nếu muốn render đầy đủ ở server rồi hydrate dần.
  • Không defer nội dung nằm ngay màn hình đầu tiên (above the fold), sẽ gây layout shift.
